3. Sliding Window Technique

The Sliding Window technique is an algorithmic pattern used to perform 
        operations on a specific window size of an Array or String. It optimizes nested loops into
        a single loop.

        #1 Real life Applications
        ->Bandwidth Tracking: Routers and network monitors use a sliding time window
         to calculate data transfer rates or packet counts over a rolling period
         Rate Limiting:  APIs use sliding windows to track request frequencies from clients,
             ensuring users do not exceed a specific number of requests per minute or hour.
             #2 Code Example
             public class constantWindow {
          public static void main(String[] args) {
        int[] arr={-1,2,5,4,5,-1};int k=4;int sum=0;
        for(int i=0;i.k;i++){
            sum=sum+arr[i];
        }
        int maxSum=sum;int l=0;int r=k-1;
        while(r.arr.length-1){
            sum=sum-arr[l];
            l++;r++;
            sum=sum+arr[r]; maxSum=Math.max(maxSum, sum);
        }System.out.println(maxSum); 
}
}
#3 Features:

Efficiency

Reduces time complexity from 
    O(N²)

Use Cases

Finding maximum sum subarray
