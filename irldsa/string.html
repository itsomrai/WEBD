01. Data Structures

Arrays

An String is a sequence of characters enclosed in quotes. In programming, strings are typically represented as arrays of characters terminated by a special character (like null in C).

#1

Real World Applications

  • Digital Images (2D/3D Arrays): Computer screens and image editing tools treat photos as large grids of pixels. Each pixel holds color values like Red, Green, and Blue.
  • Game Leaderboard: Video games track top player scores in ordered arrays to display ranks from highest to lowest.

Key Features

Fixed Size

Memory size is defined at the time of creation and cannot be dynamically resized.

Fast Access

Retrieve any element in O(1) time complexity using its index.
