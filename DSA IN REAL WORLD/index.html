1. Arrays

An Array is a collection of items stored at contiguous memory locations.
        It allows you to store multiple elements of the same type under a single variable name.

        #1 Real World Applications
 ->Digital Images (2D/3D Arrays): Computer screens and image editing tools treat photos as
         large grids of pixels. Each pixel holds color values like Red, Green, and Blue
->Game Leaderboard:Game Leaderboards: Video games track top player scores in ordered 
arrays to display ranks from highest to lowest.

2. Strings

A String is a sequence of characters enclosed in quotes. In 
        programming, strings are typically represented as arrays of characters terminated 
        by a special character (like null in C).

        #1 Real life Application
        ->Engines and Information Retrieval: Search Engines: Strings can be used
         in many search engine techniques.
        ->Web browsers and tools:Google use string matching and processing to index
         billions of web pages and find keywords matching user queries instantly

3. Sliding Window Technique

The Sliding Window technique is an algorithmic pattern used to perform 
        operations on a specific window size of an Array or String. It optimizes nested loops into
        a single loop.

        #1 Real life Applications
        ->Bandwidth Tracking: Routers and network monitors use a sliding time window
         to calculate data transfer rates or packet counts over a rolling period
         Rate Limiting:  APIs use sliding windows to track request frequencies from clients,
             ensuring users do not exceed a specific number of requests per minute or hour.
             #2 Code Example
             public class constantWindow {
          public static void main(String[] args) {
        int[] arr={-1,2,5,4,5,-1};int k=4;int sum=0;
        for(int i=0;i.k;i++){
            sum=sum+arr[i];
        }
        int maxSum=sum;int l=0;int r=k-1;
        while(r.arr.length-1){
            sum=sum-arr[l];
            l++;r++;
            sum=sum+arr[r]; maxSum=Math.max(maxSum, sum);
        }System.out.println(maxSum); 
}
}

Efficiency

Reduces time complexity from
