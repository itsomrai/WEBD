#1.WHAT IS DSA!??

DSA stands for Data Structures and Algorithms, which represents the foundational building blocks of computer science and software development.
Data structures focus on how data is organized and stored, while algorithms are the step-by-step procedures used to process that data and solve
problems efficiently.

->CORE COMPONENTS

Data Structures: The methods used to organize and store data in a computer so that it can be accessed and modified efficiently.
Examples include arrays, linked lists, stacks, queues, trees, and graphs.

Algorithms: A set of well-defined, step-by-step instructions designed to solve
a specific problem or perform a calculation. Examples include sorting algorithms 
(like Quicksort) and searching algorithms (like Binary Search).

->WHY DSA MATTERS?

Code Efficiency:It teaches you how to write programs that run faster and use less memory, which is critical when handling
large amounts of data.

Problem-Solving Skills: Mastering DSA sharpens your analytical thinking, helping you break down complex real-world problems into 
manageable, logical steps.

Technical Interviews: It is the primary subject tested during technical hiring rounds at top tech companies (like Google, Microsoft,
 and Meta).

ARRAYS

What is an Array?

An Array: is a fundamental data structure in computer programming used to store a collection of elements, typically of the same data type,
in a contiguous block of memory. Each item in an array is called an element, and its position is identified by a unique numerical index, which 
usually starts at 0. Because the data is stored sequentially, programs can access any specific element almost instantly using its index, making
arrays highly efficient for organizing and manipulating fixed-size sets of related data.

Real-World Use

E-Commerce:Product catalog filtering
Digital Photos: A digital image is a two-dimensional (2D) array of pixels. Each pixel holds color values like RGB (Red, Green, Blue)
numbers.
Display Screens:strong Computer and phone screens use multi-dimensional pixel arrays to map and refresh what you see.
Data Streams: Network cards and video streaming services use data buffers—built on arrays—to temporarily hold incoming
data packets before rendering
